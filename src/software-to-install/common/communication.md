# Communication

Chat, messaging, team collaboration, and email clients.

## Mandatory

- Slack `flatpak:com.slack.Slack` `cask:slack`
- [Telegram Desktop](https://telegram.org) `flatpak:org.telegram.desktop` `cask:telegram-desktop`
- Thunderbird `dnf:thunderbird` `apt:thunderbird` `cask:thunderbird`
  - Add-ons: Dark Reader, ImportExportTools NG, Markdown Here Revival, Own for Exchange, Thunderbird Conversations (disabled).
- Evolution email client `dnf:evolution` `apt:evolution`
- Outlook `manual`
  - Open Outlook in the browser, then right click the tab and install it as a PWA.
